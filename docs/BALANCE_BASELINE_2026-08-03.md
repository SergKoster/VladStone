# Baseline баланса v4 — 3 августа 2026

Это измерение текущих правил, а не решение о новых правилах или числах.
Источник прогона: `app/domain/combat/engine/simulation.py` (добавлен в
`f0d11b0`). Данные ниже повторно сняты после уменьшения HP дефолтной башни по
решению владельца.

## Метод

- 100 матчей, seed `0…99`;
- оба участника используют текущий детерминированный PvE-бот;
- стартовые руки и все пересборки колоды получают один воспроизводимый RNG;
- матч идёт через live-конвейер `battle → bot → resolver` до нокаута или суда;
- текущий порог суда не менялся.

## Результат

| Метрика | Значение |
|---|---:|
| Матчей | 100 |
| Длина, min / max / avg | 50 / 50 / 50.0 хода |
| Победы нижней команды | 48 |
| Победы верхней команды | 49 |
| Ничьи | 3 |

Каждый прогон дошёл до суда; уменьшение HP дефолтной башни не изменило длину
этого bot-vs-bot baseline. Нокаут башен текущая пара одинаковых стратегий не
порождает. Симметрия побед не доказывает баланс карт: она говорит только, что
у двух одинаковых стратегий нет заметного преимущества стороны на этой выборке.

## Что это значит для O10

Владелец зафиксировал цель Релиза 1: здоровый матч обычно длится **20–30
ходов** (август 2026). Поэтому текущий baseline из 50 ходов целевой диапазон
не проходит: снижение прочности башен само по себе не создаёт в нём нокаутов и
не сокращает матч.

До выбора конкретных чисел нельзя менять `JUDGEMENT_TURN`/таймеры. Следующий
полезный шаг — согласовать точные ручки и добавить сценарии с намеренными
стратегиями: спам дальников, толстяк против дальника, пустая линия и башня под
атакой (ROADMAP, Фаза 2).
