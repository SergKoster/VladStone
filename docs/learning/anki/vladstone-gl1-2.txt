Почему успешный квиз сразу после урока ничего не доказывает?	Ответ ещё лежит в рабочей памяти. Знание проверяется отсроченно (дни), без опор, и переносом на новую задачу.	gl1
Назови пять фаз PRIMM и действие в каждой.	Predict — письменный прогноз до запуска; Run — запуск и наблюдение; Investigate — трассировка и объяснение расхождений; Modify — меняю одну переменную в готовом; Make — строю похожее с нуля.	gl1
Что такое «первая ошибочная предпосылка»?	Самый ранний шаг рассуждения, где моя модель разошлась с фактом. Искать её, а не чинить последнее проявление ошибки.	gl1
Почему уверенность записывают ДО проверки?	После проверки знание результата искажает оценку — не найдёшь свои уверенные заблуждения (и свои «правильно, но не верю»).	gl1
В каком порядке просить помощь?	Уточнить условие → направляющий вопрос → область/ошибочная предпосылка → намёк без кода → похожий пример → каркас → полное решение (после него — восстановить сам).	gl1
Чем Modify отличается от Make?	Modify: меняю чужое готовое решение, опоры сохраняются. Make: строю структуру сам, без каркаса исходника.	gl1
<code>gen = get_db()</code> — сессия БД открылась?	Нет. Вызов генератора только создаёт объект-генератор; тело начнёт выполняться с первого next(). Вызов ≠ выполнение.	gl2
Когда выполняется <code>finally</code> в get_db() и от чего страхует?	При любом выходе. Ключевой случай: пока идёт запрос, генератор заморожен на yield — исключение обработчика вбрасывается прямо в эту точку, и только finally гарантирует db.close().	gl2
Чем опасен <code>suppress(Exception)</code> вокруг цикла воркера?	Прячет смерть воркера: любая ошибка молча глотается, процесс «жив», но работу не делает. Ловить можно только с логом и восстановлением.	gl2
Когда создаётся default-объект в <code>def f(x, acc=[])</code>?	Один раз — при выполнении строки def. Все вызовы делят один и тот же список: состояние утекает между вызовами (mutable default bug).	gl2
Что делает оператор <code>=</code> с объектами?	Ничего. Он не меняет и не копирует объекты — вычисляет правую часть и перевешивает имя на полученный объект.	gl2
Разница: <code>b.append(3)</code> и <code>b = b + [4]</code>?	append мутирует сам список — это видят все его имена. «+» строит новый список, а «=» перевешивает имя b на него; старый список не тронут.	gl2
Что рождает НОВЫЙ объект, а что отдаёт СТАРЫЙ?	Новый: литералы ([], [1,2]), «+», срезы (b[:]), comprehension. Старый: голое имя (x = mine), функция, вернувшая то, что ей передали.	gl2
Какой инвариант чинит замена <code>acc=[]</code> на <code>acc=None</code>?	Независимость вызовов: результат зависит только от аргументов, между вызовами нет скрытой общей памяти.	gl2
Режим отказа mutable default в веб-приложении?	<code>def search(filters: list = [])</code> — фильтры одного запроса утекают в следующий, в том числе чужому пользователю: все запросы делят один объект.	gl2
Что такое замыкание?	Функция, хранящая ссылку на enclosing frame, где живут её свободные переменные. Frame не умирает после return, пока на него есть ссылка.	gl2
Почему у <code>c1 = make_counter()</code> и <code>c2 = make_counter()</code> счётчики разные?	Каждый вызов make_counter() создаёт новый frame со своим count = 0. Две функции держат стрелки на разные frames.	gl2
Зачем <code>nonlocal</code> внутри вложенной функции?	Говорит «меняй имя в родительском frame, не заводи локальное». Без него count += 1 упал бы с UnboundLocalError.	gl2
При вызове <code>c1()</code> чьё тело выполняется?	Только тело next_value. Строка count = 0 — тело make_counter, она выполняется только при вызове самого make_counter().	gl2
Что такое инвариант?	Гарантия, истинная при любом сценарии, а не «обычно». Пример: после get_db сессия закрыта — и при успехе, и при ошибке.	gl2
Чем отличаются URL <code>postgresql://</code> и <code>postgresql+psycopg://</code>?	Схема URL выбирает драйвер: без суффикса SQLAlchemy импортирует старый psycopg2; «+psycopg» — новый psycopg 3. Ошибка «No module named psycopg2» при живом psycopg — из-за этого.	project
Как узнать, кто слушает порт 5432?	<code>netstat -ano | findstr ":5432"</code> → взять PID у LISTENING → <code>tasklist | findstr "PID"</code>.	project
Что значит <code>0.0.0.0:5432</code> в netstat?	Процесс слушает порт 5432 на всех адресах машины, включая 127.0.0.1. Формат колонки — адрес:порт.	project
Почему «чужой сервер на моём порту» хуже, чем «port already in use»?	Занятый порт падает честной ошибкой. Перехват — чужой сервер отвечает на твои подключения, и ошибка маскируется под другую («неверный пароль» при верном пароле).	project
Почему pg_isready нет на Windows, но есть в контейнере?	Программа живёт там, где её установили. Контейнер — мини-Linux, куда postgres положили вместе с его утилитами; на Windows его никто не ставил.	project
Как выполнить команду внутри работающего контейнера?	<code>docker compose exec &lt;сервис&gt; &lt;команда&gt;</code> — запускать из папки с docker-compose.yml, иначе compose не найдёт конфиг.	project
Откуда pydantic BaseSettings берёт значения и в каком приоритете?	Аргументы конструктора > переменные окружения > файл .env > умолчания в коде. Поле database_url ищется как DATABASE_URL (регистр не важен).	project
Почему при коннекте к localhost в ошибке два адреса?	localhost разворачивается в ::1 (IPv6) и 127.0.0.1 (IPv4) — клиент пробует оба. Настоящий сигнал ищи в той строке, где сервер реально ответил.	project
