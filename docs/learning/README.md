# План обучения: стек VladStone

> Цель — изучить стек проекта настолько глубоко, чтобы понимать **как работает
> каждый слой** и уверенно развивать проект как профессиональный разработчик
> (бэкенд в первую очередь, фронтенд — на уровне уверенного фулл-стэка).

## Наш стек (что именно изучаем)

| Слой | Технологии | Где в проекте |
|------|-----------|---------------|
| Язык бэкенда | Python 3.12, typing, asyncio | `VladStoneAPI/` |
| Web-фреймворк | FastAPI, Pydantic v2, uvicorn (ASGI) | `VladStoneAPI/app/api/`, `app/main.py` |
| БД | SQLAlchemy 2.0, Alembic, SQLite (dev) / PostgreSQL (prod) | `app/db/`, `alembic/` |
| Realtime | WebSockets, asyncio-воркер таймеров | `app/realtime/`, `services/combat_timer_worker.py` |
| Auth | Cookie-сессии, refresh-токены, Google OAuth/OIDC | `app/api/routes/auth.py`, `services/google_oauth.py` |
| Тесты и качество | pytest, ruff, GitHub Actions | `VladStoneAPI/tests/`, `.github/workflows/ci.yml` |
| Фронтенд | TypeScript, React 19, Vite, CSS-анимации | `VladStoneWeb/src/` |
| Инфраструктура | Docker Compose, Caddy, деплой на VPS | `deploy/`, `docs/DEPLOY.md` |
| Архитектура | Чистый домен, server-authoritative, детерминизм, события | `app/domain/combat/`, [ARCHITECTURE.md](../ARCHITECTURE.md) |

## Как проходить каждый модуль

1. **Теория** — прочитать/посмотреть ресурсы из раздела «Ресурсы» (порядок
   внутри раздела — от базового к глубокому; официальная документация всегда
   первична, курсы — опциональное дополнение).
2. **Экскурсия по коду** — открыть файлы из раздела «Где это у нас» и
   прочитать их, сопоставляя с теорией. Можно просить Claude провести разбор
   («объясни этот файл построчно», «почему здесь сделано так»).
3. **Практика** — сделать задания из раздела «Практика». Они специально
   завязаны на наш код: часть — чтение/трассировка, часть — маленькие
   изменения в песочнице (отдельная ветка, потом выбросить или влить).
4. **Квиз** — попросить Claude провести квиз по модулю (формат уже привычен
   по разборам этапов). Модуль закрыт, когда квиз пройден уверенно.

## Сквозные ресурсы (на весь путь)

- [roadmap.sh/backend](https://roadmap.sh/backend) — карта навыков
  бэкенд-разработчика; полезно сверяться, что уже покрыто, а что нет.
- [roadmap.sh/react](https://roadmap.sh/react) — то же для React.
- [Хабр: 15+ ресурсов для Python-разработчика](https://habr.com/ru/companies/yandex_praktikum/articles/750048/) —
  подборка русскоязычных материалов.
- Правило: **не смотреть курсы «запоем»** — 1 час теории → сразу час в нашем
  коде. Знание, не привязанное к проекту, выветривается за неделю.
